# EderaON

EderaON is a free, single-node tier of Edera for evaluating hardened container runtime protection on your own infrastructure.

EderaON runs each container inside its own lightweight virtual machine, giving you hardware-level isolation that stops container escapes from reaching other workloads or the host.

## Getting started

Visit [on.edera.dev](https://on.edera.dev) to create an account and get your license.
Full installation instructions are at [on.edera.dev/what-is-ederaon](https://on.edera.dev/what-is-ederaon/).
